# Doomed

NvChad's doomchad theme (its take on Doom One) for Zed, in two variants:

- **Doomed**: the original dark palette from base46
- **Doomed Light**: a light variant that mirrors the dark one, a soft slate grey rather than white

The syntax colours follow base46's tree-sitter mapping. The UI mirrors NvChad's layering: a darker file tree and pickers, a tab strip, a status bar, and vim mode colours like NvChad's statusline.

Pairs with [Doomed Icons](../icons). Generated by [`build/generate.py`](https://github.com/AlfoldiMate/doomed/blob/main/build/generate.py). Palette credit: [NvChad/base46](https://github.com/NvChad/base46), [doom-one](https://github.com/doomemacs/themes).
