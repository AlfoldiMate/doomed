# Doomchad for Zed

[NvChad](https://nvchad.com)'s doomchad theme (a Doom One variant) for Zed, in two variants:

- **Doomchad**: the original dark palette from base46
- **Doomchad Light**: a mirrored light companion, a soft slate grey rather than white

The syntax colours follow base46's tree-sitter mapping. The UI mirrors NvChad's layering: a darker file tree and pickers, a tab strip, a status bar, and vim mode colours like NvChad's statusline.

Generated by [`build/generate.py`](https://github.com/AlfoldiMate/doomzed/blob/main/build/generate.py). Palette credit: [NvChad/base46](https://github.com/NvChad/base46), [doom-one](https://github.com/doomemacs/themes).
