# Doomed Icons

A file icon theme for Zed that looks like NvChad's nvim-tree:

- The file and folder glyphs come from [nvim-web-devicons](https://github.com/nvim-tree/nvim-web-devicons) (Nerd Fonts), covering about 500 extensions and 540 file names.
- The folder and default-file glyphs match NvChad's nvim-tree config.
- Colours are the doomchad palette. Icons use base46's devicon overrides where they exist, and every other brand colour is snapped to the nearest doomchad colour.
- There are two variants, **Doomed Icons** (dark) and **Doomed Icons Light**.

Pairs with the [Doomed](../theme) theme. Glyph licences are listed in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
