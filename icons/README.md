# Doomchad Icons for Zed

A file icon theme that looks like NvChad's nvim-tree:

- The file and folder glyphs come from [nvim-web-devicons](https://github.com/nvim-tree/nvim-web-devicons) (Nerd Fonts), covering about 500 extensions and 500 file names.
- The folder and default-file glyphs match NvChad's nvim-tree config.
- Colours are the doomchad palette. Icons use base46's devicon overrides where they exist, and every other brand colour is snapped to the nearest doomchad colour.
- There are two variants, **Doomchad Icons** (dark) and **Doomchad Icons Light**.

Glyph licences are listed in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
